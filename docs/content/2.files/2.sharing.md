Un **lien de partage** donne accès à un fichier ou à un dossier à toute personne qui a le lien, **sans compte** Rocket Cloud. Il a la forme `https://cloud.exemple.com/s/<jeton>`, avec un jeton aléatoire impossible à deviner.

## Créer un lien

Dans **Mes fichiers**, choisissez **Partager** dans le menu **⋮** d'un fichier ou d'un dossier. Toutes les options sont facultatives :

| Option | Effet |
|---|---|
| **Envoyer le lien par email** | Destinataires (20 au maximum) : ils reçoivent le lien par email, envoyé en votre nom par Rocket Mailer. Un **message** peut l'accompagner. |
| **Mot de passe** | 4 caractères minimum. Demandé avant de lister ou de télécharger les fichiers. Communiquez-le par un autre canal : il n'est pas dans l'email. |
| **Téléchargements max.** | Au-delà, le lien ne fonctionne plus. Vide : illimité. |
| **Expire le** | Date et heure après lesquelles le lien ne fonctionne plus. |

**Créer le lien** affiche l'adresse, avec un bouton pour la copier.

::note
L'email n'est envoyé que si l'administrateur a relié Rocket Cloud à Rocket Mailer. Sinon, le lien est bien créé et vous le transmettez vous-même. Voir [Notifications par email](/administration/storage#notifications-par-email).
::

## Ce que voit le destinataire

La page du lien affiche le nom du fichier ou du dossier, la personne qui l'a partagé, votre message et la date d'expiration :

- pour un **fichier**, un bouton **Télécharger** ;
- pour un **dossier**, la liste de ses fichiers, **sous-dossiers compris**, chacun avec son bouton **Télécharger** ;
- si le lien est protégé, un champ **Mot de passe** d'abord : ni la liste ni les fichiers ne sont accessibles sans lui ;
- s'il est limité, le nombre de téléchargements restants.

Un lien expiré, épuisé, supprimé, ou dont le propriétaire a été désactivé, affiche **Lien indisponible** avec la raison.

Un lien vers un dossier suit son contenu : un fichier ajouté au dossier après la création du lien est aussi partagé.

## Mes partages

**Mes partages** liste vos liens, les plus récents en premier, avec :

- leur état : **Actif**, **Expiré** ou **Épuisé**, et le badge **Mot de passe** s'il y a lieu ;
- le nombre de téléchargements (sur le maximum) et la date d'expiration ;
- l'état de l'email : en cours d'envoi, envoyé, ou non envoyé avec la raison ;
- **Copier le lien**, et la suppression.

Supprimer un lien le rend **immédiatement** inutilisable ; le fichier ou le dossier, lui, reste dans votre espace. Un lien ne se modifie pas : pour changer une option, supprimez-le et créez-en un autre.

## Sécurité

- Le mot de passe d'un lien est **haché** : Rocket Cloud ne le conserve pas en clair et ne peut pas le retrouver.
- Le mot de passe est envoyé dans le corps de la requête (`POST`), jamais dans l'adresse : il n'apparaît ni dans l'historique du navigateur ni dans les journaux du serveur.
- Les fichiers sont toujours téléchargés, jamais affichés comme une page du site : un fichier HTML partagé ne peut pas exécuter de script.
