**Mes fichiers** est votre espace personnel : personne d'autre n'y a accès, pas même les administrateurs. Le dossier ouvert apparaît dans l'adresse de la page (`/files?folder=…`) : vous pouvez l'ajouter à vos favoris, et le bouton Retour du navigateur fonctionne.

## Déposer des fichiers

- Cliquez sur **Déposer** et choisissez un ou plusieurs fichiers ;
- ou glissez-les depuis votre poste sur la page : ils rejoignent le dossier ouvert.

Tous les types de fichiers sont acceptés. Un fichier trop volumineux, ou qui dépasserait votre quota, est refusé avec la raison ; les autres sont bien déposés.

La jauge en haut à droite indique l'espace utilisé sur votre quota (10 Go par défaut). Elle passe à l'orange au-delà de 90 %.

::tip
Depuis le tableau de bord, l'action rapide **Déposer des fichiers** ouvre directement le choix des fichiers.
::

## Ranger

- **Nouveau dossier** crée un dossier dans le dossier ouvert. Les dossiers s'imbriquent sans limite pratique ; le fil d'Ariane permet de remonter.
- Le menu **⋮** d'un fichier ou d'un dossier propose **Renommer**, **Déplacer** (vers n'importe quel dossier, ou la racine) et **Supprimer**.

Un nom ne peut pas contenir `/` ni `\`. Un dossier ne peut pas être déplacé dans lui-même ni dans l'un de ses sous-dossiers.

::warning
La suppression est **définitive** : il n'y a pas de corbeille. Supprimer un dossier supprime aussi ses sous-dossiers, tous leurs fichiers et les liens de partage qui y mènent.
::

## Ouvrir et télécharger

Cliquez sur le nom d'un fichier :

- les images (PNG, JPEG, GIF, WebP), les PDF, le texte, l'audio et la vidéo s'ouvrent dans un nouvel onglet ;
- les autres fichiers se téléchargent.

**Télécharger**, dans le menu **⋮**, télécharge toujours le fichier, quel que soit son type.

## Rechercher

Le champ **Rechercher un fichier…** cherche dans les noms de fichiers de **tous** vos dossiers, pas seulement celui qui est ouvert.

## Partager

**Partager**, dans le menu **⋮** d'un fichier ou d'un dossier, crée un lien public. Voir [Partager](/files/sharing).

## Fichiers déposés par une application

Une application (CRM, ERP…) autorisée à agir en votre nom peut déposer des fichiers dans votre espace, par exemple un document qu'elle a généré. Ils apparaissent dans **Mes fichiers** comme les autres, et comptent dans votre quota. Voir [l'API Fichiers](/api/files).
