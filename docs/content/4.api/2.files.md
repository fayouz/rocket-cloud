Toutes les requêtes demandent un utilisateur : un JWT, ou une application qui impersonne un utilisateur (`Authorization: Bearer rca_…` + `X-Impersonate-User`). Voir [Authentification](/api/authentication).

Chaque requête travaille dans l'espace de **cet** utilisateur : les listes ne contiennent que ses dossiers et ses fichiers, administrateurs compris. Un dossier ou un fichier d'un autre utilisateur donne `403` ou `404`.

## Déposer un fichier

`POST /api/files`, en `multipart/form-data` :

| Champ | Rôle | Défaut |
|---|---|---|
| `file` | Le fichier, de tout type | requis |
| `folder` | Identifiant du dossier (ou `/api/folders/<id>`) | la racine |
| `name` | Nom du fichier dans Rocket Cloud | nom du fichier envoyé |

```bash [Terminal]
curl -X POST https://cloud.exemple.com/api/files \
  -H "Authorization: Bearer rca_…" \
  -H "X-Impersonate-User: alice@exemple.com" \
  -H "Accept: application/json" \
  -F file=@devis.pdf \
  -F folder=0199… -F name="Devis 2026-042.pdf"
```

La réponse (`201`) est le fichier :

```json
{
  "id": "01a0…",
  "name": "Devis 2026-042.pdf",
  "folder": "/api/folders/0199…",
  "size": 48213,
  "mimeType": "application/pdf",
  "sha256": "9f86d08…",
  "previewable": true,
  "createdAt": "2026-09-25T10:12:00+00:00",
  "updatedAt": "2026-09-25T10:12:00+00:00",
  "createdBy": "alice@exemple.com",
  "updatedBy": "alice@exemple.com"
}
```

Le type (`mimeType`) est détecté d'après le contenu, pas d'après l'extension. `previewable` indique si le navigateur peut l'afficher (images PNG, JPEG, GIF, WebP, PDF, texte, audio, vidéo).

| Erreur | Cause |
|---|---|
| `413` | Fichier trop gros (`CLOUD_MAX_FILE_SIZE`), ou quota de l'utilisateur dépassé (`CLOUD_DEFAULT_QUOTA`) |
| `422` | Champ `file` manquant, dossier inconnu ou appartenant à un autre utilisateur |
| `403` | Application sans utilisateur (`X-Impersonate-User` manquant) |

## Espace utilisé

```bash [Terminal]
curl https://cloud.exemple.com/api/files/usage -H "Authorization: Bearer …" -H "Accept: application/json"
# → { "used": 734003200, "quota": 10737418240, "maxFileSize": 536870912, "files": 42 }
```

Tailles en octets. À appeler avant un dépôt pour vérifier qu'il passera.

## Lister les fichiers

`GET /api/files` liste les fichiers de l'utilisateur, par nom. Filtres :

| Paramètre | Effet |
|---|---|
| `folder=<id>` | Fichiers d'un dossier (sans ses sous-dossiers) |
| `exists[folder]=false` | Fichiers à la racine |
| `name=devis` | Recherche partielle dans le nom, sans tenir compte de la casse |
| `mimeType=image/` | Type qui commence par cette valeur |
| `order[size]=desc` | Tri par `name`, `size`, `createdAt` ou `updatedAt` |
| `page`, `itemsPerPage` | Pagination |

Sans filtre de dossier, la liste couvre **tous** les dossiers.

## Lire un fichier

| Requête | Effet |
|---|---|
| `GET /api/files/{id}` | Les métadonnées du fichier |
| `GET /api/files/{id}/content` | Le contenu : affiché par le navigateur (`inline`) s'il est `previewable`, téléchargé sinon |
| `GET /api/files/{id}/content?download=1` | Le contenu, toujours en téléchargement |

```bash [Terminal]
curl -o devis.pdf https://cloud.exemple.com/api/files/01a0…/content?download=1 \
  -H "Authorization: Bearer rca_…" -H "X-Impersonate-User: alice@exemple.com"
```

Le contenu est servi avec une politique de sécurité stricte (`Content-Security-Policy: … sandbox`, `X-Content-Type-Options: nosniff`) : un fichier ne peut jamais s'exécuter comme une page de l'API.

## Renommer, déplacer, supprimer un fichier

```bash [Terminal]
curl -X PATCH https://cloud.exemple.com/api/files/01a0… \
  -H "Authorization: Bearer …" -H "Content-Type: application/merge-patch+json" \
  -d '{"name": "Devis signé.pdf", "folder": "/api/folders/0199…"}'
```

`"folder": null` ramène le fichier à la racine. `DELETE /api/files/{id}` le supprime définitivement, avec son contenu et ses liens de partage (`204`).

Un nom ne peut pas contenir `/` ni `\` (255 caractères au maximum).

## Dossiers

| Requête | Effet |
|---|---|
| `GET /api/folders` | Dossiers de l'utilisateur, par nom. Filtres : `parent=<id>`, `exists[parent]=false` (racine), `name` (partiel) |
| `GET /api/folders/{id}` | Un dossier, avec son chemin depuis la racine (`path`) |
| `POST /api/folders` | `{ "name": "Devis", "parent": "/api/folders/0199…" }` (`parent` : `null` pour la racine) |
| `PATCH /api/folders/{id}` | Renommer (`name`) ou déplacer (`parent`) |
| `DELETE /api/folders/{id}` | Supprime le dossier, ses sous-dossiers, tous leurs fichiers et leurs liens de partage |

```json
{
  "id": "0199…",
  "name": "Devis",
  "parent": "/api/folders/0198…",
  "path": [
    { "id": "0198…", "name": "Clients" },
    { "id": "0199…", "name": "Devis" }
  ],
  "createdAt": "2026-09-25T09:00:00+00:00",
  "updatedAt": "2026-09-25T09:00:00+00:00",
  "createdBy": "alice@exemple.com",
  "updatedBy": "alice@exemple.com"
}
```

Un dossier ne peut pas être déplacé dans lui-même ou dans l'un de ses sous-dossiers, ni sous un dossier d'un autre utilisateur (`422`). Un nom ne peut pas contenir `/` ni `\`.
