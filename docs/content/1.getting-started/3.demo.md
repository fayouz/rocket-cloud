La démo lance Rocket Cloud avec des données prêtes à l'emploi :

- des comptes locaux et LDAP (annuaire OpenLDAP) ;
- pour Alice, un dossier **Projets** avec deux fichiers (« Note de lancement.txt » et « Tarifs 2026.csv ») ;
- un lien de partage public vers « Tarifs 2026.csv », avec un message ;
- une application externe, avec un jeton connu, qui peut agir au nom des utilisateurs.

::tabs
  :::tabs-item{label="En local" icon="i-lucide-laptop"}
  ```bash [Terminal]
  docker compose -f compose.yaml -f compose.demo.yaml up -d --build
  ```

  Puis ouvrez http://localhost:3200 (Rocket Cloud) et http://localhost:3201 (cette documentation et le changelog).
  :::

  :::tabs-item{label="GitHub Codespaces" icon="i-simple-icons-github"}
  1. Sur GitHub : **Code → Codespaces → Create codespace**.
  2. Attendez la fin de la commande de démarrage (quelques minutes la première fois).
  3. Ouvrez le port 3200 (Rocket Cloud) depuis l'onglet **Ports**.
  :::
::

## Comptes

| Compte | Mot de passe | Type |
|---|---|---|
| `admin@example.org` | `demo-admin-password` | local, administrateur |
| `alice@example.org` | `demo-alice-password` | local |
| `marie.martin@example.org` | `password` | LDAP, administratrice par son groupe `rocket-admins` |
| `jean.dupont@example.org` | `password` | LDAP |

## Scénarios

1. **Ranger ses fichiers.** Connectez-vous avec `alice@example.org` et ouvrez **Mes fichiers** : le dossier **Projets** contient les deux fichiers de démo. Créez un sous-dossier, glissez-y des fichiers depuis votre poste, ouvrez un PDF ou une image dans le navigateur, puis déplacez ou renommez un fichier.
2. **Ouvrir un lien de partage.** Dans **Mes partages**, copiez le lien vers « Tarifs 2026.csv » et ouvrez-le dans une fenêtre de navigation privée : la page publique affiche le message d'Alice et le bouton **Télécharger**, sans compte. Le compteur de téléchargements augmente.
3. **Partager un dossier protégé.** Dans **Mes fichiers**, choisissez **Partager** sur le dossier **Projets**, avec un mot de passe et 3 téléchargements au maximum. Ouvrez le lien : la page demande le mot de passe avant de lister les fichiers. Supprimez ensuite le lien dans **Mes partages** : il ne s'ouvre plus.
4. **Espaces privés.** Connectez-vous avec `admin@example.org` : **Mes fichiers** est vide, les fichiers d'Alice ne sont pas visibles. Le tableau de bord montre en revanche les chiffres de toute la plateforme.
5. **Application.** Une application dépose un fichier dans l'espace d'Alice :
   ```bash [Terminal]
   curl -X POST http://localhost:3200/api/files \
     -H "Authorization: Bearer rca_demo_rocket_auth_do_not_use_in_production" \
     -H "X-Impersonate-User: alice@example.org" -H "Accept: application/json" \
     -F file=@document.pdf
   ```
   Le fichier apparaît à la racine de **Mes fichiers** d'Alice.

::note
La démo ne comprend pas Rocket Mailer : un partage avec des destinataires est bien créé, mais **Mes partages** indique que l'email n'est pas parti (« Rocket Mailer n'est pas configuré »). Voir [Notifications par email](/administration/storage#notifications-par-email).
::

::warning
Les mots de passe et le jeton de la démo sont publics : ne l'exposez pas sur Internet.
::
